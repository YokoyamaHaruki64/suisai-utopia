# 水彩ユートピア

Windows のコンソールで動く C++ のアクションシューティングです。弾や爆弾、敵の出現、フィールドの塗り処理を実装し、タイトル・練習・ゲーム・リザルトの画面を切り替えます。

- `player.cpp`、`bullet.cpp`、`bomb.cpp` にプレイヤーと攻撃処理があります。
- `enemySpawn.cpp`、`paintMap.cpp`、`collision.cpp` で敵の出現、フィールドの塗り、衝突判定を確認できます。

配布された学内用のライブラリを使用しており、それらはgitから外しているのでビルド不可となっています。

## コミット履歴について

就職活動で制作物を紹介するため、制作後に Git リポジトリとして整理しました。そのため、制作中の変更はコミット履歴に残っておらず、コミット数も少なくなっています。
